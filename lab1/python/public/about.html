Про роботу

Опис реалізації: сервер написано на Python з використанням лише вбудованих модулів http.server та pathlib, без фреймворків та сторонніх бібліотек.

Запит обробляється так: сервер отримує шлях запиту, відкидає рядок параметрів (query string), зіставляє шлях із таблицею маршрутів i зчитує відповідний HTML- або CSS-файл із каталогу public/ за допомогою read_text. Якщо шлях не входить у таблицю маршрутів, сервер повертає сторінку 404.html зі статусом 404, без перенаправлення — адреса в браузері лишається незмінною.

Content-Type задається явно: text/html; charset=utf-8 для HTML-сторінок та text/css; charset=utf-8 для файлу стилів.
